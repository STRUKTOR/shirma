# Ширма — обезличивание документов для работы с Claude Code

Заменяет персональные данные и реквизиты (ФИО в любом падеже, организации, ИИН/БИН, IBAN, карты,
телефоны, почту, домены) на реалистичные фейки, а после работы Claude возвращает настоящие данные.
Всё локально, без сети. Подробности — [docs/DESIGN.md](docs/DESIGN.md).

## Установка (один раз на ноутбук)

1. Установить [uv](https://docs.astral.sh/uv/getting-started/installation/).
2. В папке репозитория: `uv sync --extra dev`.
3. Установить скилл для Claude Code: `uv run shirma install-skill`. После этого в любой сессии
   Claude Code можно сказать «создай рабочую папку Ширмы» — Claude спросит место, проверит его
   и создаст папку.
4. Или создать рабочую папку вручную: `uv run shirma init ~/Shirma/<название>`.

Не создавайте рабочую папку в iCloud Drive, Dropbox, OneDrive, Google Drive, Яндекс Диске,
в «Документах» и на «Рабочем столе», если они синхронизируются с iCloud, и внутри git-репозиториев:
оригиналы с персональными данными уйдут в облако или в коммит. `shirma init` предупредит об этом;
`shirma init <папка> --dry-run` только проверяет место.

В рабочей папке появятся ярлыки «1-Обезличить», «2-Проверить», «3-Вернуть», папка `private/` (оригиналы, результаты, служебное) и `claude/` (папка проекта для Claude Code).

### Как попросить Claude создать рабочую папку

Скилл `shirma-init` срабатывает, когда в просьбе ясно, что речь о рабочей папке Ширмы. Надёжнее всего
упомянуть Ширму и сразу указать место.

С местом — Claude проверит его и сразу создаст папку:

- «Создай рабочую папку Ширмы в ~/Shirma/Ромашка»
- «Заведи папку Ширмы для клиента Ақжол»
- «Настрой Ширму для бухгалтерии в ~/Shirma/buh»

Без места — Claude спросит, где создать, и предложит `~/Shirma/<название>`:

- «Создай рабочую папку Ширмы»
- «Подготовь папку для обезличивания документов»
- «Хочу поработать с конфиденциальными договорами — подготовь место через Ширму»

Обновить существующую папку после обновления Ширмы (ярлыки, настройки и скиллы обновятся, данные
останутся):

- «Обнови рабочую папку Ширмы ~/Shirma/Ромашка»

Вызвать скилл напрямую, без угадывания: `/shirma-init` или `/shirma-init ~/Shirma/Ромашка`.

Слово «Ширма» лучше оставлять: без него «создай папку для документов» может не вызвать скилл,
и Claude создаст обычную папку.

После создания Claude переведёт сессию в `<папка>/claude` и проверит, что защита включилась
(в десктоп-приложении), или попросит открыть там новую сессию (в терминальном `claude`).

## Работа

1. Положить файлы в `private/input`, дважды щёлкнуть «1-Обезличить», затем «2-Проверить».
2. Открыть Claude Code в папке `claude` и работать с файлами из `input/`; результаты — в `output/`.
3. Дважды щёлкнуть «3-Вернуть» — готовые файлы в `private/output`.

В чате с Claude можно просто сказать «обезличь новые файлы» или «верни данные в результаты» — это сделает скилл `shirma`, который `init` кладёт в папку `claude`. Команды печатают только количества.
